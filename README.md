## Installation

1. Clone this repository:

```sh
git clone https://github.com/mitchelljcodes/dotfiles
```

2. Remove current dotfiles:

```sh
rm -rf ~/.config 
```

3. Copy new dotfiles:

```sh
cp -r dotfiles/home/.config ~
```

Enjoy!
